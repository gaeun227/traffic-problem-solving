# 데이터 보관

공모전 분석에 사용할 **공개 가능하고 이용조건을 확인한 데이터**를 이 폴더에서 관리한다.

- 원자료를 추가하기 전에 제공기관, 출처 URL, 확인일, 라이선스, 시간·공간 단위를 `../research/sources.csv`에 기록한다.
- 원자료는 수정하지 않고, 가공한 자료와 구분한다.
- 대용량 원자료를 둘 `raw/`와 제한 자료를 둘 `private/`는 Git 추적에서 제외된다. 개인정보·개인위치정보·영업비밀 등은 저장소에 올리지 않는다.
- 분석 결과를 공유할 때는 재현 방법과 데이터의 이용조건을 함께 기록한다.
