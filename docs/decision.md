# 주제 선택: 검증 관문

주제는 발표의 인상보다 **마감일까지 입증 가능한 결과**를 기준으로 선택한다. 각 관문에 `통과 / 불확실 / 실패`를 적고 근거 파일·URL을 연결한다.

## 첫 검증 실험

### 후보 1

1. 특정 지역·평일 1주일을 택해 03:30~05:30 이동 수요 자료의 실제 제공 형태를 확인한다.
2. 같은 시간대 버스·철도 운행 자료와 공간적으로 결합한다.
3. 식별 가능한 것은 `새벽 이동 수요`인지 `필수노동자 통근`인지 구분한다.
4. 후보 셔틀 1개 노선을 만들고 차량 수·운행거리·탑승률에 따른 순배출량을 계산한다.

### 후보 2

1. 주요 간선축 1개와 짧은 기간을 정해 교통량·속도·도로길이를 같은 링크·시간 단위로 결합한다.
2. 차종 구성과 속도별 배출계수의 공식 출처·적용 범위를 확인한다.
3. 기준속도를 여러 방식으로 바꿔 추가배출량의 민감도를 계산한다.
4. 신호 제어 효과를 주장하려면 신호 현시·정차 횟수 등 별도 자료 또는 시뮬레이션이 가능한지 확인한다.
