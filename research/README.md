# 근거와 데이터 기록

`sources.csv`는 확인한 원자료를 기록한다. 주장의 검증 여부와 실제 데이터 확보 여부를 혼동하지 않는다.

## 상태값

- `후보`: URL이나 자료명이 제시됐지만 원출처 확인 전
- `확인`: 원출처와 설명·이용조건을 읽음
- `표본확보`: 작은 표본을 실제로 받거나 열어 변수·단위를 확인함
- `분석사용`: 분석 코드에 연결함
- `부적합`: 필요한 단위·권한·품질을 충족하지 못함

자료마다 제공기관, 원본 URL, 확인일, 이용조건, 기간, 시간·공간 단위, 주요 변수, 제한사항을 적는다. 사본을 보관할 경우 원본과 전처리본을 분리한다.
